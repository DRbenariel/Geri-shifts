# Design System — המערך הגריאטרי Admin Frontend
> Generated by ui-ux-pro-max analysis — Healthcare / RTL / Clinical Precision variant
> Applied: 2026-05-27

---

## 1. Design Philosophy

**Archetype:** Precision Instrument Panel  
**Mood:** Clinical authority, zero decorative noise, high-stakes data legibility  
**Constraint:** Hebrew RTL throughout — no language toggle, no mixed-script headings  
**Density:** Information-dense (data tables, KPI cards, bar charts) — comfort on 1280px+ screens

Healthcare-specific rules applied:
- Alert hierarchy is strict: critical (red) > warning (amber) > informational (blue)
- Status tags must be scannable at a glance — always dot + label, never label alone
- Numeric data stays LTR even inside RTL containers (`dir="ltr"` on numeric spans)
- LED status indicators: exactly 8px diameter, glow radius 2× diameter
- Scanline overlay ≤ 12% opacity to prevent eye strain on data-dense views
- No decorative gradients on content areas — only on structural chrome (header, accent lines)

## 3. Typography Scale

**Font family:** Heebo (Google Fonts) — all weights 300/400/500/700/900  
**Rationale:** Heebo is designed specifically for Hebrew — superior legibility at small sizes, clean numerals, consistent rhythm across RTL and LTR segments.

| Token | Size | Weight | Letter-spacing | Usage |
|---|---|---|---|---|
| `--type-label` | 11px | 500 | 0.08em | Column headers, meta labels (all-caps) |
| `--type-body` | 13px | 400 | 0 | Table cells, descriptions |
| `--type-caption` | 11px | 300 | 0.06em | Timestamps, secondary meta |
| `--type-title` | 15px | 700 | 0.04em | Panel titles, section titles |
| `--type-heading` | 20px | 900 | 0.01em | Page section headings |
| `--type-kpi` | 52px | 900 | -0.02em | KPI display numbers |
| `--type-nav` | 13px | 400→700 | 0.04em | Nav items (700 when active) |

## 5. Component Patterns (healthcare-specific)

### Alert Banner
- Severity levels: `critical` (red right-border 3px), `warning` (amber right-border 3px), `info` (blue right-border 2px)
- Left side: LED dot + text. Right side: timestamp + action button
- Always sticky at top of tab content, never dismissible during session (admin sees all alerts)
- Pulsing LED only on `critical` severity

### KPI Cards
- Label **above** number (cognitive load: context before value)
- Unit/sub text below in `--text-dim`
- Top accent line = 1px in semantic color with glow
- Numbers: large weight (900), semantic color, `text-shadow` glow
- Grid: 3 columns desktop, 2 columns ≤600px, 1 column ≤380px

### Data Tables (RTL)
- All text columns: `text-align: right` (RTL default)
- Numeric columns: `<span dir="ltr">` wrapper inside `<td>` — numbers read LTR
- Header row: all-caps, `--type-label` size, `--text-dim` color
- Row hover: `--bg-row` background transition 150ms
- Sticky first column (rightmost in RTL): `position: sticky; right: 0`

### Status Tags
- Always: colored dot (5px, matching semantic color) + label text
- Never use color alone — dot + label required for accessibility
- Sizes: `--type-label` (11px/500)

### LED Indicators
- Diameter: exactly 8px (not 7px)
- `box-shadow`: `0 0 6px <color>, 0 0 12px <color-glow>` (double shadow for depth)
- Pulsing animation only on active alert states

### Bar Chart
- Track height: 4px (slimmer = more precision feel)
- Fill endpoint glow: `filter: brightness(1.6) blur(1px)` on a 2px cap
- Name column: fixed `min-width: 88px`, right-aligned

### Nav Bar
- Text only, no icons
- RTL: `justify-content: flex-end` so first item appears rightmost
- Active: `--amber-hi` color + `font-weight: 700` + 2px bottom amber line (not 1px) with glow
- Height: 48px (touch-friendly)

## 6. Structural Chrome

### Scanline Overlay
- Opacity: **10%** max (`rgba(0,0,0,.10)`)  
- Pattern: 4px cycle (3px transparent + 1px dark)  
- `pointer-events: none`, `z-index: 9999`

### Dot Grid
- Color: `#1A2840` (1px dot)  
- Grid size: 28px × 28px  
- Correct as-is

### Header Amber Line
- 2px gradient: `transparent → --amber → transparent`  
- Opacity: 0.6  
- Correct as-is

---

## 7. Anti-Patterns (do not use)

- ❌ `unicode-bidi: bidi-override` on number cells (breaks numeral direction)
- ❌ Scanline opacity > 12% (eye strain)
- ❌ Nav icons (adds visual noise, not clinical)
- ❌ Rounded corners (`border-radius`) — instrument panels use sharp edges
- ❌ Gradient backgrounds on content cards (only on structural chrome)
- ❌ Shadows on table rows (use background color change instead)
- ❌ More than 3 semantic colors on a single view
